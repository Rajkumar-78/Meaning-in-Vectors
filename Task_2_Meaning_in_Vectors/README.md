# Task 2 — Meaning in Vectors

## Run
`pip install -r requirements.txt`, then open and run `notebook.ipynb`.

## Output
The notebook prints the 6x6 cosine similarity matrix, three most similar sentence pairs, the least similar pair, a semantically related password pair, and a PCA scatter plot with labels.

Similarity scores and PCA coordinates are generated by the installed model/library versions. They may vary slightly across versions; the notebook computes them rather than hard-coding sample values.
